# Changelog Entry Template
#
# HOW TO USE:
#   1. Copy the block between the dashed lines below
#   2. Paste it at the TOP of CHANGELOG.md, just after "# Changelog"
#   3. Fill in version, date, and content
#   4. Delete sections/bullets you don't need
#   5. Save — the viewer will pick it up immediately (no restart needed)
#
# FORMAT RULES (parser depends on these):
#   - Version header MUST be:  ## [x.x.x] - YYYY-MM-DD
#   - Section headers:         ### Section Name
#   - Sub-section headers:     #### Sub-section Name
#   - Bullet points:           - Item text
#   - Bold text:               **bold**
#   - Inline code:             `code`
#   - Separator between versions: ---
# ──────────────────────────────────────────────────────────────

## [x.x.x] - YYYY-MM-DD

### Bug Fixes
- **`path/to/file.py` — Short bug title**: What was wrong and what changed.
- **Frontend — Short bug title**: What was wrong and what changed.

### New Features

#### Feature Group Name
- **`new_file.py`** *(new)*: What it does, key endpoints or functions.
- **`existing_file.py`**: What changed and why.
- **`templates/newsroom.html`**: What UI elements or JS functions were added.

#### Another Feature Group
- **Backend**: Describe backend changes.
- **Frontend**: Describe frontend changes.

### Improvements
- **Short title**: What improved and the impact.

### Removals / Breaking Changes
- **`file.py`**: What was removed and why.
