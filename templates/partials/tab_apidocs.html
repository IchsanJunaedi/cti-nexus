API Documentation

Base URL: http://<host>:<port>  ·  All protected endpoints require Authorization: Bearer <token> header or cti_auth cookie.

Authentication
POST /api/auth/login Obtain JWT token 
{ "username": "user", "password": "pass" }
Returns: { "access_token": "...", "token_type": "bearer" }. Store token and send as Authorization: Bearer <token>.
POST /api/auth/logout Invalidate current session · auth required
GET /api/auth/me Current user profile · auth required
POST /api/auth/change-password Change own password · auth required 
{ "current_password": "...", "new_password": "..." }
GET /api/auth/audit-log Paginated audit log · admin required
page Page number (default 1)
page_size Results per page
Articles
GET /api/articles List articles with filters
search Substring match on title/body
country Filter by country
industry Filter by industry
actor Filter by threat actor
date_start ISO date (YYYY-MM-DD)
date_end ISO date (YYYY-MM-DD)
page Page number (default 1)
page_size Results per page (default 20)
dedup true to collapse duplicates
dedup_threshold Cosine similarity threshold (default 0.75)
GET /api/articles/{article_id} Single article detail · auth required
GET /api/articles/dedup-groups Inspect semantic duplicate groups
days Lookback window (default 7)
threshold Cosine similarity (default 0.75)
GET /api/dashboard Dashboard statistics (counts, trends, top actors)
GET /api/filters Available filter options (countries, industries, actors)
IOC Management
GET /api/iocs List / search IOCs · auth required
ioc_type ip | domain | url | url_with_path | email | sha256 | sha1 | md5 | cve
search Substring match on value
page Page number (default 1)
page_size Max 200 (default 50)
sort_by last_seen | confidence
GET /api/iocs/stats Count by type + confidence summary · auth required
GET /api/iocs/{ioc_type}/{value} Full detail for one IOC · auth required
POST /api/iocs/{ioc_id}/feedback Mark true / false positive · auth required 
{ "verdict": "tp" | "fp", "note": "optional string" }
POST /api/iocs/{ioc_type}/{value}/tags Add tags to IOC · auth required 
{ "tags": ["ransomware", "apt29"] }
POST /api/iocs/{ioc_type}/{value}/threat-actors Link threat actors to IOC · auth required 
{ "threat_actors": ["APT28", "Lazarus"] }
DEL /api/iocs/{ioc_type}/{value}/threat-actors/{actor} Unlink a threat actor · auth required
DEL /api/iocs/{ioc_id} Delete IOC · admin only
POST /api/iocs/bulk-delete Bulk delete IOCs · admin only 
{ "ids": ["<ioc_id>", "..."] }
GET /api/iocs/allowlist List IOC extraction allowlist · auth required
POST /api/iocs/allowlist Add allowlist entry · admin only 
{ "type": "domain" | "ip", "value": "example.com" }
DEL /api/iocs/allowlist/{entry_id} Remove allowlist entry · admin only
